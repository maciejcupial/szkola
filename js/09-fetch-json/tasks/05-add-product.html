Zadanie 5 (dla chętnych): dodajemy produkt przez API

Do tej pory JavaScript tylko pobierał dane. Teraz wyśle nowy produkt do serwera: metodą POST, w formacie JSON. Gotowy plik 05-add-product.php zapisuje produkt w bazie i odsyła go z nadanym numerem id.

  1. W handleSubmit(event) zatrzymaj przeładowanie strony przez event.preventDefault().
  2. Wyślij fetch("05-add-product.php", { method: "POST", headers: …, body: … }). Nagłówek "Content-Type": "application/json" mówi serwerowi, że w treści jest JSON, a JSON.stringify() zamienia obiekt na tekst JSON.
  3. Odpowiedź zamień przez await response.json(). Gdy response.ok jest fałszem, pokaż pod formularzem komunikat z data.error.
  4. Gdy się udało, dopisz produkt do listy „Dodane teraz” i wyczyść oba pola.
  5. Sprawdź: dodaj „Linijka” za 2.40, potem wyślij formularz z pustą nazwą, na koniec dodaj <b>Test</b> za 1. Otwórz ../index.html: nowe produkty są w bazie.
