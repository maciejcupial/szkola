Zadanie 2: API z tanimi produktami

Tym razem gotowy jest JavaScript, a Ty piszesz stronę serwera. Plik 02-cheap-products.php ma wysłać w formacie JSON tylko produkty tańsze niż 10 zł.

  1. Wyślij zapytanie SELECT id, name, price FROM products z warunkiem WHERE price < 10.
  2. W pętli while z mysqli_fetch_assoc() dopisz każdy wiersz do tablicy $products.
  3. Otwórz sam plik 02-cheap-products.php w przeglądarce: widać tekst JSON z dwoma produktami.
  4. Otwórz tę stronę: lista pokazuje Długopis i Zeszyt, a pod nią „Tanich produktów: 2”.
